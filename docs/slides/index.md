# F Slides

## Summary

Each handbook module can have one slide deck for teaching it live. Decks are labelled by origin: ✋ handcrafted decks are written and approved by a person and set the standard for a good deck; 🤖 auto-generated decks are produced by a program from the module's text using a fixed formula. A handcrafted deck replaces a generated one for the same module once approved, and handcrafted decks stay off the site until approved.
